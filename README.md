
# Weather App

This is a desktop weather website built with React and Vite. It uses the OpenWeather API to display current weather and a 5-day forecast for any city. The interface is interactive and user-friendly.

## Features
- Search weather by city
- Display current weather
- Show 5-day forecast
- Responsive and modern UI

## Getting Started

1. Install dependencies (if not already):
	```sh
	npm install
	```
2. Start the development server:
	```sh
	npm run dev
	```
3. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Configuration
- You will need an API key from [OpenWeather](https://openweathermap.org/api). Create a `.env` file in the root directory and add:
  ```
  VITE_OPENWEATHER_API_KEY=your_api_key_here
  ```
